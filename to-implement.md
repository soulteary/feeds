# Podcast RSS support

The iTunes / Apple Podcasts fields formerly listed here are supported by the
optional ITunesFeed / ITunesItem models and the existing XML extension API.
See the README for construction, omission, namespace, and compatibility rules.

Apple requirements: https://podcasters.apple.com/support/823-podcast-requirements
Apple RSS guide: https://help.apple.com/itc/podcasts_connect/en.lproj/itcb54353390.html

Additional Podcast Namespace vocabularies (such as chapters and transcripts)
can be supplied through Extensions; dedicated typed models are not included.

# v1.3.1

This maintenance release updates the validation environment used for the
independent `github.com/soulteary/feeds` module.

## Changes

- Use Go 1.27.4 for reporting, security checks, and the current-toolchain
  Linux/macOS/Windows compatibility jobs.
- Update checkout, Go setup, and artifact actions to their current releases,
  pinned to full commit hashes.
- Keep the Go 1.20 compatibility job and the module's zero-dependency baseline.

There are no feed API or serialization changes in this release. Consumers
continue to require Go 1.20 or later; the CI toolchain update does not raise
the module's minimum Go version. Historical benchmark and validation records
retain the toolchain versions on which they were measured.

## Install

```sh
go get github.com/soulteary/feeds@v1.3.1
```
